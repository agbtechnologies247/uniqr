# Shadcn/ui & Radix UI Primitives System

## Guidelines
1. **Unstyled Accessibility Primitives**: Build modals, dialogs, dropdowns, and tabs using Radix UI accessible state primitives.
2. **Copy-Paste Component Ownership**: Place component primitives directly in the codebase for total styling freedom without library lock-in.
3. **Tailwind Class Merging**: Combine base component styles with caller overrides cleanly via `clsx` and `tailwind-merge`.
