# UI/UX Pro Max Design System Guidelines

## Core Principles
1. **Curated Color Tokens over Defaults**: Never use raw browser colors or basic primary colors. Utilize high-contrast, harmonious palettes (e.g. Deep Obsidian `#030712`, Cyber Indigo `#3B82F6`, Electric Cyan `#06B6D4`, Neon Violet `#8B5CF6`, Soft Emerald `#10B981`).
2. **Layered Surface Depth**: Use semi-transparent glassmorphic panels with subtle multi-border highlights (`border-white/10` and `border-cyan-500/20`).
3. **Structured Spacing Scale**: Enforce consistent padding (`p-4`, `p-6`, `p-8`) and grid gaps.
4. **Visual Rhythm**: Clear visual hierarchy separating hero metrics, primary interactive elements, and supporting technical logs.
