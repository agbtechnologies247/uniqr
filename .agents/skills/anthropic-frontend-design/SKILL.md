# Anthropic Frontend Design Taste & Hierarchy System

## Principles
1. **Typography & Character**:
   - Use high-quality Google Fonts (Plus Jakarta Sans for UI text, Outfit for displays & headings, JetBrains Mono for codes/identifiers).
   - Explicitly avoid generic default browser fonts or overused unstyled typography.
2. **Anti-Cliché Aesthetic**:
   - Avoid standard boring card grids. Use asymmetrical highlight cards, gradient stroke borders, ambient backlight halos, and micro-badges.
3. **Information Density with Restraint**:
   - Balance dense data tables/logs with generous padding and crisp divider lines (`border-slate-800/80`).
4. **Color intentionality**:
   - Primary: Deep Space Obsidian (`#030712`)
   - Accent Primary: Electric Cyan (`#06B6D4`)
   - Accent Secondary: Neon Violet (`#8B5CF6`)
   - Accent Positive: Emerald Glow (`#10B981`)
