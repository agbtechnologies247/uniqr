# Bit & Styleguidist Component Sharing

## Guidelines
1. **Atomic Component Architecture**: Decouple buttons, badges, modals, and card primitives into reusable atomic units.
2. **Living Style Guide**: Maintain clear props API definitions and living interactive documentation.
3. **Cross-Project Portability**: Ensure components rely exclusively on design system tokens rather than hardcoded global CSS.
